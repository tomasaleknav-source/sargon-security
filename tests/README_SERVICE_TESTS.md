ServiceTests.cs naudoja tik lokalią kriptografijos bandymo pažymą build/service-test-cert/test.pfx (test-only). Ji neplatinama. Norint pakartoti host testus, sugeneruokite savo vienos dienos RSA2048 testinę pažymą ir PFX su bandymo slaptažodžiu test-only. Tai nėra programos leidėjo raktas ir negali būti naudojama galutiniam pasirašymui. Tikri Windows bandymai pateikti Service/Invoke-NativeAcceptance.ps1. QA_STATUS.json yra dabartinės laidos patikrų būsena; ankstesniais numeriais pažymėti QA failai ir žurnalai yra istorija.
